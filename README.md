# ショッピングカート

[🇯🇵 日本語](README.md) | [🇺🇸 English](README.en.md)

このショッピングカートアプリは、TypeScript、React、Vite、Bootstrap、Context API、およびローカルストレージを使用して構築されています。ユーザーは商品をカートに追加したり、各商品の数量を調整したり、合計金額を確認したりできます。

## 使用技術
- TypeScript
- React
- Vite
- Bootstrap
- Context API
- ローカルストレージ

## インストール
このアプリケーションを使用するには、お使いのマシンにNode.jsとnpmがインストールされている必要があります。これらの依存関係がインストールされたら、以下の手順に従ってください。

1. リポジトリをローカルマシンにクローンします。

2. プロジェクトディレクトリで`npm install`を実行して、必要な依存関係をインストールします。

3. プロジェクトディレクトリで`npm run dev`を実行して、開発サーバーを起動します。

4. Webブラウザを開き、`http://localhost:3000`にアクセスしてアプリケーションを使用します。


## 使用方法
商品をカートに追加するには、商品カードの「カートに追加」ボタンをクリックしてください。各商品の数量は、商品名の横にある「+」ボタンと「-」ボタンで変更できます。商品をカートから削除するには、商品名の横にある「削除」ボタンをクリックしてください。合計金額はカート画面下部に表示されます。


## 貢献方法
このプロジェクトに貢献したい場合は、以下の手順に従ってください。

1. このリポジトリをフォークします。
2. フォークしたリポジトリをローカルマシンにクローンします。
3. 変更用の新しいブランチを作成します。`git checkout -b my-new-branch`
4. 変更を加えてコミットします。`git commit -m "Add some feature"`
5. ブランチにプッシュします。`git push origin my-new-branch`
6. 新しいプルリクエストを作成します。
